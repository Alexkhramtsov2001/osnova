# Работа с проектом ОСНОВА

- Это портфолио вайб-кодера. Цены, сроки, кабинет, чат и Supabase демонстрационные. Платный сервер и коммерческие функции не требуются.
- Перед правками изучайте текущий код, README и состояние Git; сохраняйте пользовательские изменения.
- Сохраняйте цвета, типографику, изображения и композицию; меняйте дизайн в пределах задачи пользователя.
- Не выдавайте концепции и демонстрационные данные за готовые дома, утверждённые тарифы или реальный клиентский сервис.
- Демо-таблицы Supabase принимают только предусмотренные коды и параметры, без контактов посетителей и свободного текста.
- Проверяйте затронутые сценарии, типы, линтер и сборку. При изменении пользовательских сценариев запускайте Playwright.
- Завершённые правки автоматически отправляйте в GitHub, проверяйте CI и публикацию.
- Отчёты по работе предоставляйте в чате; не добавляйте новые файлы аудита без запроса пользователя.
