# ОСНОВА

**[Открыть живое демо →](https://alexkhramtsov2001.github.io/osnova/)** · [Проверки CI](https://github.com/Alexkhramtsov2001/osnova/actions/workflows/ci.yml)

Портфолио вайб-кодера: интерактивный сайт вымышленной строительной компании.

От выбора дома и сравнения концепций — до подробного расчёта и PDF.

Интерфейс адаптирован для телефона, планшета и компьютера.

Цены, сроки, кабинет, заявки и чат демонстрируют возможности реализации.

Проект использует бесплатный Supabase; отдельный платный сервер не требуется.

**Стек:** React 19 · TypeScript 6 · Vite 8 · React Router · Supabase · jsPDF · Vitest · Playwright · GitHub Actions.

## Что можно попробовать

- Выбрать один из восьми домов: фильтры, страницы концепций, избранное и сравнение до трёх вариантов.
- Пройти подбор: семь зависимых вопросов, рекомендация с объяснением либо переход к своему расчёту.
- Настроить площадь, этажность, комнаты, материалы, регион, доставку и состав восьми этапов; увидеть условную стоимость, срок и детализацию.
- Скачать PDF, скопировать сводку, сохранить до восьми расчётов в браузере и восстановить параметры. Текущий черновик сохраняется в этой вкладке при переходах между страницами.
- Открыть демо-кабинет, попробовать готовые ответы чата и отправить тестовую заявку в Supabase.

Все проекты и расчёты условные. Избранное и расчёты хранятся локально. Демо-вход использует готовые тестовые реквизиты. Supabase принимает только ограниченные тестовые параметры без контактов и свободного текста посетителей. Контакты автора открывают почту, Telegram и ВКонтакте для самостоятельной отправки сообщения.

## Локальный запуск

Нужны Node.js 24 и npm.

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm run typecheck
npm run lint
npm run format:check
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

CI выполняет проверки типов, стиля, форматирования, модульные и браузерные тесты, затем production-сборку. Публикация на GitHub Pages настроена отдельным workflow; базовый путь — `/osnova/`, прямые ссылки поддерживаются через `404.html`.

## Структура

```text
src/pages/            Главная, проект дома и сравнение
src/components/       Общие элементы интерфейса
src/features/         Калькулятор, подбор, кабинет, проекты и демо-интеграции
e2e/                  Браузерные сценарии Playwright
supabase/             SQL-миграции и проверки прав
docs/                 Описание проекта и данные
docs/archive/         Исторические отчёты и прежняя дорожная карта
```
