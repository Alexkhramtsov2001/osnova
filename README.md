# ОСНОВА

**[Открыть живое демо →](https://alexkhramtsov2001.github.io/osnova/)** · [Проверки CI](https://github.com/Alexkhramtsov2001/osnova/actions/workflows/ci.yml)

Портфолио вайб-кодера: интерактивный сайт вымышленной строительной компании.

От выбора дома и сравнения концепций — до подробного расчёта и PDF.

Интерфейс адаптирован для телефона, планшета и компьютера.

Цены, сроки, кабинет, заявки и чат демонстрируют возможности реализации.

Проект использует бесплатный Supabase; отдельный платный сервер не требуется.

**Стек:** React 19 · TypeScript 6 · Vite 8 · React Router · Supabase · jsPDF · Vitest · Playwright · GitHub Actions.

## Что можно попробовать

- Выбрать один из восьми домов: фильтры, страницы концепций, избранное и сравнение до трёх вариантов.
- Пройти подбор: семь зависимых вопросов, рекомендация с объяснением либо переход к своему расчёту.
- Настроить площадь, этажность, комнаты, материалы, регион, доставку и состав восьми этапов; увидеть условную стоимость, срок и детализацию.
- Посмотреть варианты оплаты и предварительную сводку выбранного расчёта: этапы, доставку, условную скидку и статус НДС. Банковские программы приведены как примеры без партнёрства и без подачи заявки.
- Скачать PDF, скопировать сводку, сохранить до восьми расчётов в браузере и восстановить параметры. Текущий черновик сохраняется в этой вкладке при переходах между страницами.
- Открыть демо-кабинет, попробовать готовые ответы чата и отправить тестовую заявку в Supabase.

Все проекты и расчёты условные. Избранное и расчёты хранятся локально. Демо-вход использует готовые тестовые реквизиты. Supabase принимает только ограниченные тестовые параметры без контактов и свободного текста посетителей. Контакты автора открывают почту, Telegram и ВКонтакте для самостоятельной отправки сообщения.

## Страницы

| Маршрут                              | Содержимое                                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------------------------- |
| `/`                                  | Слайд-шоу, три популярных проекта, преимущества, переход к расчёту, демонстрационные отзывы |
| `/projects`                          | Полный каталог, фильтры, избранное и сравнение                                              |
| `/projects/:id`                      | Концепция выбранного дома                                                                   |
| `/calculator`                        | Полный калькулятор, сохранения и PDF                                                        |
| `/payment`                           | Варианты оплаты и демонстрационная сводка после расчёта                                     |
| `/about`                             | Вымышленная история, показатели, команда и принципы                                         |
| `/partners`                          | Шесть вымышленных партнёров и три иллюстративных кейса                                      |
| `/vacancies`                         | 55 демонстрационных вакансий, фильтры и локальная имитация отклика                          |
| `/contacts`                          | Контакты автора, демо-чат и локальная форма без отправки и хранения                         |
| `/compare`, `/find-home`, `/account` | Сравнение, подбор и демонстрационный кабинет                                                |

Старые ссылки `/#projects`, `/#project-01`, `/#calculator`, `/?project=01#calculator`, `/#contacts` и `/#demo-chat` перенаправляются к новым страницам. Фильтры и выбор сохраняются при переходах внутри приложения; черновик калькулятора — в `sessionStorage` вкладки. Корпоративные данные, навигация и SEO находятся в `src/features/company/`. Портреты команды сгенерированы для проекта и не изображают реальных сотрудников. Новые разделы не подключают серверы; существующие демо-интеграции Supabase сохранены.

## Локальный запуск

Нужны Node.js 24 и npm.

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm run typecheck
npm run lint
npm run format:check
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

CI выполняет проверки типов, стиля, форматирования, модульные и браузерные тесты, затем production-сборку. Публикация на GitHub Pages настроена отдельным workflow; базовый путь — `/osnova/`, для 19 маршрутов создаются отдельные HTML-точки входа с уникальными метатегами; `404.html` поддерживает неизвестные адреса. Генерируются `sitemap.xml` и `robots.txt`. Это клиентское React-приложение, не серверный рендеринг.

## Структура

```text
src/pages/            Главная, каталог, калькулятор, компания, партнёры, контакты и проекты
src/components/       Общие элементы интерфейса
src/features/         Калькулятор, подбор, кабинет, проекты и демо-интеграции
scripts/              Генерация статических точек входа и SEO при сборке
e2e/                  Браузерные сценарии Playwright
supabase/             SQL-миграции и проверки прав
docs/                 Описание проекта и данные
docs/archive/         Исторические отчёты и прежняя дорожная карта
```
