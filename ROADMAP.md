# Развитие ОСНОВЫ

ОСНОВА — портфолио вайб-кодера. Проект показывает законченные пользовательские сценарии с демонстрационными данными и бесплатным Supabase. Платный сервер и коммерческие функции не входят в текущую цель.

## Готовые сценарии

- Каталог восьми концепций, фильтры, страницы домов, избранное и сравнение до трёх проектов.
- Подбор дома по семи зависимым вопросам из банка из 15 тем.
- Калькулятор восьми этапов с материалами, регионом, доставкой, условными ценами и сроками.
- Сводка расчёта, PDF, до восьми локальных сохранений и восстановление параметров.
- Демо-кабинет и локальный диалог по проектам.
- Тестовая заявка и готовые темы чата через Supabase без контактов посетителей.
- Адаптивный интерфейс, автоматические проверки и публикация на GitHub Pages.

## Приоритеты дальнейших улучшений

1. Завершить и согласовать всю документацию проекта, включая [спецификацию демо-генератора чертежей](docs/DRAWING_GENERATOR_SPEC.md). До этого не начинать функциональный код генератора и другие новые функции.
2. Исправлять обнаруженные ошибки сценариев, мобильного интерфейса и доступности после завершения документационного этапа.
3. Проверять совместимость на реальных устройствах, особенно в Safari.
4. Поддерживать наглядную презентацию проекта: демо, скриншоты и краткую документацию.

## Следующий портфолио-этап: демо-генератор чертежей

Владелец планирует автоматическую выдачу PDF и DXF с демонстрационными планами и условными конструктивными схемами частных домов. Файлы не предназначены для строительства и продажи проектов. Сначала нужно согласовать пользовательский сценарий, границы генерации, состав листов и формат DXF в [спецификации](docs/DRAWING_GENERATOR_SPEC.md). Текущий сайт такой функции не имеет.

## Возможные эксперименты

Демонстрационная админ-панель может стать отдельной портфолио-задачей. Она не является обязательным условием готовности действующего сайта.

Коммерческие цены, реальные аккаунты, синхронизация и приём клиентских обращений потребуют нового решения о назначении проекта.

[Прежняя подробная дорожная карта](docs/archive/ROADMAP_2026-10-14.md) сохранена вместе с историческими отчётами. [Последний аудит](docs/AUDIT_2026-10-14.md) описывает проверку на указанную дату; актуальные результаты тестов доступны в GitHub Actions.
