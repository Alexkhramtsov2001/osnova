# Промежуточный аудит ОСНОВЫ — 14 октября 2026

## Результат

Сайт собирается и проходит статические и unit-проверки. Восемь фотографий каталога уже хранились в репозитории локально; внешние ссылки на фото в рабочем интерфейсе не обнаружены. Фотографии уменьшены до ширины 1000 px и пересохранены в JPEG: общий вес снизился с 2,68 МБ до 1,61 МБ (примерно на 40%). Удалены неиспользуемые файлы изображений из стартового шаблона.

## Что проверено

- Каталог и слайд-шоу используют локальные файлы из `public/images/projects/`.
- В коде нет URL внешних фотохостингов; внешние адреса относятся к Supabase RPC, контактным ссылкам и шрифту.
- GitHub Pages собирается с базовым путём `/osnova/`; workflow создаёт `404.html` из `index.html` для прямых ссылок React Router.
- Формирование PDF загружается динамически при запросе пользователя, а не входит целиком в начальную загрузку.
- Supabase использует только publishable key в браузере; миграции и документация описывают ограничения демо-заявок без персональных данных.

## Проверки

- `npm run typecheck` — пройдено.
- `npm run lint` — пройдено.
- `npm test` — 71 тест, все пройдены.
- `npm run format:check` — пройдено.
- `npm run build` — пройдено.
- `git diff --check` — пройдено.
- `npm run test:e2e` — локально проверить не удалось: Chromium завершается при запуске с `bootstrap_check_in … Permission denied (1100)` до открытия страницы. Поэтому browser-тесты не дают информации о поведении приложения в этом окружении; их нужно подтвердить CI GitHub Actions.

## Оставшиеся пункты

1. В `src/index.css` остаётся `@import` Google Fonts. Это единственная лишняя внешняя загрузка для оформления страницы; при желании можно следующим шагом локально разместить совместимый шрифт и убрать сетевой запрос.
2. Playwright в локальном macOS-окружении заблокирован системными правами. Проверка сценариев браузера остаётся за CI и ручной проверкой опубликованного сайта на Safari/iPhone.
3. Сайт остаётся портфолио-демо: цены, сроки и проекты условные; Supabase заявки и чат хранят только тестовые данные без контактов пользователя. Это описано в README и `docs/SUPABASE_APPLICATIONS.md`.

Аудит не выявил дополнительных проблем, требующих изменения калькулятора, маршрутов или схемы Supabase в рамках этой задачи.
