# Иллюстративные фотографии домов

В каталоге и слайд шоу использованы стоковые фотографии экстерьеров. Они подобраны по характеру, окружению и примерной этажности демонстрационных концепций ОСНОВЫ. Это **не фотографии построенных компанией домов** и не точное изображение будущего проекта. Планировки и конструктивные решения по ним не определяются.

Снимки сохранены локально в `public/images/projects/`, чтобы сайт работал без загрузки фотографий с внешнего сервера. Изображения уменьшены до ширины 1000 пикселей и повторно сохранены в JPEG для сокращения загрузки. После оптимизации файлы весят 1,61 МБ вместо 2,68 МБ — на 40% меньше; изображения визуально проверены в каталоге и слайд-шоу. Все восемь страниц источников при подборе обозначали изображения как бесплатные по [лицензии Unsplash](https://unsplash.com/license) (проверено 12.10.2026). Условия лицензии допускают использование на сайте; указание автора приветствуется. Перед коммерческой публикацией стоит повторно проверить источники и заменить иллюстрации на согласованные материалы компании.
