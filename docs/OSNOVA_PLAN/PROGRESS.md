- osnova-plan — отдельное локальное приложение рядом с github-checkout, собственная ветка main без коммитов и remote. Код/тесты не входят в репозиторий сайта; интеграции, публичного стенда и разрешения Q01 пока нет.
- B01–B13 завершены в границах фундамента: оболочка React/Vite, модель черновика и runtime-проверка, версионированные правила, doubled-mm/areaQ4 и BigInt-арифметика, сериализация в памяти, узкий адаптер прямых стен на основе OpenCalque, union L/T/X с учётом материалов, свободные области/контуры/привязка комнат, явная нормализация, геометрический валидатор этажа, preview/confirm/cancel в памяти, фиксированный SVG-просмотр и проверяемый backup.
- C01 завершён как предпроверка наружного габарита/округления и происхождения manual/calculator/catalog с исходным snapshot и последующими изменениями. Это transient-состояние, не интеграция с сайтом и не сохранённый полный Project.
- C02 завершён как предпроверка требований комнат, состава/нижнего бюджета и hard/soft связей. Логический граф не доказывает геометрическое размещение, реальные проходы или приватность.
- C03 in_progress: реализованы интервалы/отступы проёмов (C03.1), привязка физических комнат к требованиям (C03.2a), фактические стороны/размеры по роли/пересечения/обязательные окна (C03.2b), геометрия открывания 90° (C03.3a), столкновения с сопряжёнными стенами и true void (C03.3b1).
- C03.3b1 учитывает собственные door/passage cuts, не выдаёт окно за проход и не скрывает стену приоритетом учёта материалов. Модель движения — идеальное полотно нулевой толщины; разрешённое чистое касание не означает реальный монтажный зазор. Коллизии между дверями ещё не проверены: doorPairValidationRequired/swingCollisionValidationRequired=true. Успех узкой проверки не означает валидный дом.
- В Project геометрические коллекции пока пустые, geometryStatus=notGenerated; производные данные ядра не выданы за готовый канонический проект. src/core/index.ts уже экспортирует реальные API; существует 16 unit-файлов и два e2e-файла, но их наличие не означает свежий полный прогон.
- Script backup реализован через scripts/backup.mjs: create/verify/restore в новую папку. Script check отсутствует. Конкретные команды сверять с package.json и локальным README.
