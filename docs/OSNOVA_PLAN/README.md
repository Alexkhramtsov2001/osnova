## Как продолжать экономно

Прочитать применимый AGENTS, локальный `osnova-plan/PROGRESS.md`, одну карточку задачи и только названные в ней разделы. Полный архив и исследование доноров не перечитываются при каждом запросе. Одна задача — один запрос; при превышении области сначала разделить на подзадачи с прежним критерием. Не начинать следующие карточки автоматически.

Работа идёт в соседнем `osnova-main/osnova-plan`, вне `github-checkout`. Код и тесты пока только локально. Документацию сайта разрешено commit/push; исходники генератора этим разрешением не охватываются. Первый отдельный HTTPS-деплой — после подтверждения владельца на Q01, а интеграция сайта — поздний E.

- Точная модель и согласованные допуски; самостоятельный законченный MVP раньше мебели, редактора и сметы.
- Полная v1.0 со всеми прежними обязательствами после MVP; CAD/3D — дальнейшие выпуски.
- [Резервная копия до v3](archive/pre-v3-2026-10-20/README.md), [предложения Claude и ChatGPT](archive/sources/README.md).

Blender скачан по сообщению владельца, но установка/версия/MCP ещё не проверены. Ядро, 2D и браузерный 3D не требуют Blender у посетителя.
