## Как продолжать экономно

Прочитать применимый AGENTS, последнюю датированную запись локального `osnova-plan/PROGRESS.md`, одну карточку задачи и только названные в ней разделы. README читать как текущий указатель, длинные файлы — ограниченными диапазонами. Полный журнал, архив и исследование доноров не перечитываются при каждом запросе. Одна задача — один запрос одному исполнителю; при превышении области сначала разделить на подзадачи с прежним критерием. Не начинать следующие карточки автоматически.

Согласовано 03.11.2026: пока хватает баланса DeepSeek, штатно две независимые задачи одновременно — Codex и один DeepSeek Harness без вложенных агентов. До запуска координатор закрепляет ID/результат, зависимости, пакет чтения, отдельные файлы записи, проверки и стоп-условия. Общие журналы, приёмку, backup и документационный Git ведёт только координатор. При зависимости или отсутствии подходящей второй задачи область не расширять ради занятости второго исполнителя; исходники генератора остаются локальными.

Бюджет простой задачи DeepSeek — 0,5 CNY со всеми платными инструментами, контрольная остановка по оценке 0,35 CNY. Начальный предел простой задачи — 12 обращений к модели или 5 минут, денежный порог раньше; достигнутый предел означает отчёт о незавершённой работе, не автоматическое продолжение. Flash/low по умолчанию, краткий контекст, веб только по задаче (первоначально до 10 успешных Search/Fetch), без Pro/max и общих аудитов по собственной инициативе. Профильный предел 8192 выходных токена относится к одному обращению; ни он, ни RTK не гарантируют денежный лимит целого задания. Расход проверять по доступной телеметрии, отделяя оценку от счёта платформы; баланс, ключи и журналы аккаунта не публиковать. Подробные постоянные правила — локальный `osnova-plan/docs/DEVELOPMENT_PROCESS.md`.

Уточнение владельца: для сложного кода не ограничивать качество искусственным Low или бюджетом простой задачи. До запуска выделить небольшой проверяемый срез, достаточный effort/контекст/проверки и отдельные границы денег/времени/обращений; больший платный бюджет согласовать числом заранее. Глобальный экономный профиль не повышать для всех задач. Декомпозиция, один DeepSeek без субагентов и правило остановки неработающей ветви сохраняются.

Работа идёт в соседнем `osnova-main/osnova-plan`, вне `github-checkout`. Код и тесты пока только локально. Документацию сайта разрешено commit/push; исходники генератора этим разрешением не охватываются. Первый отдельный HTTPS-деплой — после подтверждения владельца на Q01, а интеграция сайта — поздний E.
