# OSNOVA PLAN — действующая документация и архив v2.1–v2.14

Этот каталог перенесён из предоставленного владельцем архива `OSNOVA_PLAN_TZ_v2_1-v2_14.zip` от 15.10.2026. Технические главы, справочные материалы и чек-листы скопированы без изменений. Исходные файлы `README.md` и `AGENTS.md` сохранены как [SOURCE_README.md](SOURCE_README.md) и [SOURCE_AGENTS.md](SOURCE_AGENTS.md), чтобы архивные правила не подменяли действующий `AGENTS.md` в корне репозитория.

**Начинать чтение с [целевой концепции](PRODUCT_VISION.md), [модели CAD-редактора](CAD_ARCHITECTURE.md) и [плана расширения](RELEASE_PLAN.md).** OSNOVA PLAN развивается от локального браузерного 2D-планировщика до многофункционального CAD-редактора без ИИ и серверной обработки. Архивные исключения DXF, 3D, сложных контуров, фасадов и разрезов ограничивают первый выпуск, а не дальнейшее развитие. Рабочие строительные чертежи — отдельная поздняя цель, требующая своей спецификации и проверки. Прежняя краткая спецификация PDF/DXF-генератора Codex удалена, поскольку она не описывала планировщик.

Для долгосрочной цели действует `PRODUCT_VISION.md`; для алгоритмов первого выпуска — технические главы архива, если они не противоречат более поздним решениям владельца. Открытые параметры перечислены в `references/OPEN_DECISIONS.md`. Эта страница и обзорные документы не превращают запланированные функции в уже реализованные.
