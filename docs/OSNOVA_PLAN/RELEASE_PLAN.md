# OSNOVA PLAN — этапы и расширение функций

Статус: план возможностей, не график сроков и не поручение писать код. Применяется вместе с [целевой концепцией](PRODUCT_VISION.md). Исходная дорожная карта `docs/13_ROADMAP.md` остаётся перечнем работ для ограниченного первого планировщика; этот план показывает дальнейшее развитие без платных серверов и ИИ. Этапы B–E — внутренние части **первой публичной версии планировщика** из архива. Расширенные свободные CAD-команды начинаются на этапе F.

Этапы могут делиться на небольшие задачи; порядок отдельных функций внутри этапа уточняется после согласования сценариев. Первый публичный выпуск содержит планировщик, хранение и экспорт из архива; этапы F–H расширяют его позже и не выдаются за уже реализованные функции. Реализация остаётся локальной для пользовательских данных. Бесплатный статический хостинг, память/производительность устройства и поддержка браузеров проверяются на каждом этапе; тяжёлые модули загружаются по необходимости.

Для каждой функции заранее фиксировать: пользовательский сценарий, типы данных, операции и ошибки, критерии точности, поддержку браузеров, формат файла и тест приёмки. Для OSS отдельно фиксировать версию, лицензию и результат пробы в текущем React/Vite/GitHub Pages окружении. Завершённые изменения в репозитории отправляются в GitHub автоматически по действующему `AGENTS.md`; архивный запрет push не действует.
