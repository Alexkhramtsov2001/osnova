# Правила Codex для OSNOVA PLAN

## Обязательное правило №1
Codex **непосредственно создаёт и редактирует реальные файлы** в доступной локальной папке проекта либо подключённом репозитории. Ответы с кодом в чате, инструкциями для ручного копирования или ZIP вместо внесённых изменений не считаются реализацией. При отсутствии доступа на запись честно сообщить об этом.

## До изменений
Проверить `git status`, ветку, пользовательские изменения, актуальные `package.json`, маршруты, README, документацию. Прочитать полный комплект ТЗ. Не писать функциональный код до явного разрешения на конкретный этап. Проверить лицензии OSS.

## Во время работы
Сохранять React/TypeScript/Vite и функциональность сайта. Один канонический источник геометрии. Точные площади ±0,005 м². Не отправлять проекты автоматически в Supabase. Не подменять интерактивный планировщик PDF/DXF-генератором. Не изменять продуктовый объём самостоятельно.

## После работы
Запускать применимые lint, typecheck, tests, build, затем просмотреть diff. Сообщать реальные результаты проверок, изменённые файлы и ограничения. Не утверждать, что тесты пройдены, если они не запускались.

## Git
**Запрещены автоматический push в main, merge, force push, reset --hard, удаление веток и файлов без отдельного разрешения.** Работать в согласованной ветке, сохранять незакоммиченные пользовательские изменения. Коммиты и PR — по согласованному процессу.
