Дата: 15 октября 2026. Статус: техническая спецификация для согласования и последующей разработки, не готовый код.

**Продукт:** локальный браузерный 2D-планировщик домов в существующем сайте OSNOVA. Пользователь задаёт габариты, этажность, строгие чистые площади комнат, соседства, предпочтения; алгоритм генерирует допустимый план. Пользователь редактирует геометрию, сохраняет проекты в IndexedDB, экспортирует `.osnova` и PDF, получает геометрическую предварительную смету.

**Это НЕ сокращённый демо-генератор PDF/DXF.** Документ `docs/DRAWING_GENERATOR_SPEC.md`, ранее добавленный Codex, противоречит согласованной концепции в части отсутствия редактора, локального хранения и сметы. DXF, фасады и конструктивные чертежи не входят в обязательный MVP. Продукт не предназначен для выдачи инженерной/рабочей документации для строительства.

Читать `AGENTS.md`, затем главы `docs/` по порядку. При конфликтах не менять требования без согласования. Репозиторий этим архивом не изменяется.
