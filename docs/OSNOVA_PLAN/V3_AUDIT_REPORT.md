# OSNOVA PLAN v3.0 — аудит объединения документации

Дата: 20.10.2026. Это документационный аудит, не инженерная экспертиза и не результат исполнения ещё отсутствующего генератора.

## Вердикт по источникам

Промт ChatGPT улучшает порядок работы: законченный MVP раньше полного CAD, отдельные источники требований, независимые испытания, контрольные точки настоящего iPhone, приёмка и commit/push. Принят с уточнением: прямо указанные полномочия владельца важнее общих фраз промта, исходники пока локальны, первое HTTPS-размещение требует отдельного согласия. Документация не запускает B02.

Claude полезен как критика прежней тяжёлой последовательности и риска тестов, повторяющих ошибку генератора. Не принят механически: обычные целые mm, растр 10 мм как точный oracle, обязательный generate до его реализации, слабая доказанность корпуса и несуществующие scripts создают ошибки. Текущий B01 у Claude не был доступен, поэтому он не основание начинать подготовку с нуля.

## Что отложено и что сохранено

MVP не включает мебель/эргономику, два этажа, редактор/компенсацию, смету и офлайн reload; **все они обязательны в полной v1.0**, с конкретными T/R/W/S карточками. Стабильная модель/точные площади/валидатор/Controller/версии/Worker/сохранение/файлы/PDF не отложены из фундамента/MVP.

L3/L4, 10 мм, новые контуры/свободный CAD/SVG/DXF относятся к F. Производные 3D/фасады/разрезы — G. DWG/IFC/BIM/твердотельное ядро и профессиональная методика — H с отдельными проверками/специалистом. Рабочие чертежи не выдаются за готовый результат концептуального PDF.

## Проверка существующего проекта

По реальным файлам B01 подтверждён: оболочка/типизация/конфигурации, пустой публичный core, три viewport smoke. B02 и продуктовые модули отсутствуют. Исторический PROGRESS сообщает успешные проверки B01; в этой задаче они не повторялись и не выданы за новый тест. Пакеты/код/тесты/конфигурации не менялись; локальные README/AGENTS/PROGRESS обновлены только для продолжения по v3.

## Проверки документации

При финальной проверке обязательны: Prettier Markdown, локальные ссылки и anchors, 119 уникальных ID, существование зависимостей/отсутствие циклов, полнота mapping 93 прежних карточек, объективные поля приёмки/команд, ZIP entries/hashes относительно HEAD до v3, неизменность non-doc файлов генератора и отсутствие исходников в Git diff, git diff --check.

Фактические результаты заключительной проверки записаны ниже после её выполнения; unit/E2E/typecheck/build сайта или генератора в документационной задаче не запускаются. Git SHA и успешность push сообщаются после реальной отправки в итоговом сообщении. Нельзя заранее записывать completed в Q/M или продуктовые гейты.

Проверено перед коммитом: 59 Markdown-файлов текущего комплекта/указателей/локальных журналов, 161 локальная ссылка и 6 anchors без ошибок; 119 уникальных карточек с обязательными полями, все зависимости существуют, циклов нет, closure MVP содержит 47 карточек. Таблица соответствует всем 93 прежним ID. ZIP имеет 31 уникальный исходный путь, содержимое каждого сверено с прежним HEAD; SHA-256 совпадает с архивным README. SHA-256 всех 20 non-doc файлов отдельного генератора не изменились. Git diff содержит только документацию и намеренный резервный ZIP; исходники/тесты/CI не затронуты. Форматирование изменённых Markdown и diff проходят; локальные README/AGENTS/PROGRESS также проверены Prettier. Это не подтверждает ни одного продуктового гейта или реального Safari.

## Остающиеся риски и вопросы

- Бounded поиск может не достичь порогов даже на proof-корпусе: сначала контрпример/профилирование и отдельная задача, не ослабление судьи.
- Совместимость OpenCalque с собственной точностью/ID ещё не доказана; адаптер B06 может потребовать более узкий перенос.
- Формальная независимость файлов не гарантирует независимого понимания математики: нужны ручные значения, exact oracle и mutations.
- Численные строительные шаблоны демонстрационные. Комфорт и инженерная безопасность не доказываются арифметикой.
- Реальная полнота/время выявятся на C16/T06/S04; срок «3–4 недели» не подтверждён наблюдениями.
- Ранний хостинг/remote, согласие на первый deploy, конкретный workflow обновления и устройство владельца пока не выбраны/не подтверждены; не блокируют B02.
- Заявление о двух поддержанных версиях Safari нельзя подтвердить одним текущим iPhone; незакрытая среда остаётся ограничением.
- 25 поздних направлений — не полностью рассчитанные алгоритмы на годы вперёд: перед ними нужны небольшие собственные контракты.
- Документационный push текущей задачи помечается [skip ci], чтобы не публиковать основной сайт. Это не отключение проверок кода; существующие workflows не изменяются.

## Следующее действие

После публикации документации остановиться. Следующее отдельное программирование — **B02**, типы и runtime-схема минимального проекта в локальном osnova-plan, с целевыми unit-тестами. Не начинать B02 этим поручением.
