# Протокол каждой задачи Codex

1. Прочитать полное ТЗ и `AGENTS.md`.
2. Проверить прямой доступ к проекту, ветку и `git status`.
3. Определить конкретные файлы и критерии приёмки.
4. Создать/изменить **реальные файлы** проекта.
5. Добавить тесты, запустить проверки и исправить ошибки.
6. Проверить diff, не затронуть посторонние файлы.
7. Отчёт: сделано, файлы, команды/результаты, ограничения, Git status.
8. Не пушить в main без разрешения и не начинать следующий этап без приёмки.
