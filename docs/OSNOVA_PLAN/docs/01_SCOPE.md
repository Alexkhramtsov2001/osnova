# v2.1 — Назначение и границы

OSNOVA PLAN — интерактивный локальный 2D-генератор и редактор планировок частных домов, часть сайта OSNOVA. MVP: прямоугольный наружный контур, один или два этажа с общими наружными габаритами; технологии газобетон, керамический блок, кирпич, каркас. Помещения имеют точные чистые площади, предпочтения соседств, этажей и ориентации. Генератор выдаёт один лучший допустимый вариант; допускаются холлы, коридоры, лестницы и явно обозначенные нераспределённые области. Сгенерированные помещения прямоугольные; ручные объединения могут давать ортогональные вогнутые полигоны.

Редактор: стены, проёмы, лестница в рамках ограничений, мебель, функциональные зоны; Undo/Redo и предпросмотр компенсации. Desktop SVG; mobile — просмотр, формы, генерация, смета, экспорт без прецизионной правки. IndexedDB и `.osnova`, PDF A3/A4, геометрическая смета, офлайн после загрузки ресурсов. Без регистрации для расчёта, без серверной загрузки планов.

Не включать BIM, 3D, DXF, инженерные сети, фасады/разрезы, профессиональные конструктивные расчёты, сертифицированные строительные чертежи, автоматическую облачную синхронизацию. Результаты демонстрационные и ориентировочные.
