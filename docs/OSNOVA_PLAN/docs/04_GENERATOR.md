# v2.4 + v2.13-C — Генератор и оптимизация

**Задача:** найти планировку L, удовлетворяющую всем hard constraints, затем максимизировать score. Недопустимая планировка не может быть выбрана из-за высокого score.

Переменные комнаты: x,y,w,h,floor; стены, проёмы, лестница, топология. Площадь считается по внутренним поверхностям **после построения стен**. Hard constraints: точная чистая площадь ±0,005 м²; отсутствие пересечений; габарит; допустимые размеры/пропорции и обязательная мебель по шаблону; этажные и обязательные соседства; доступ через двери/лестницу; locked несущие стены; допустимые проёмы; согласованная лестница и плита; точный баланс площадей.

**Pipeline (9 стадий):** 1 предварительная проверка ввода; 2 распределение комнат по этажам; 3 топологический шаблон (центральный/боковой коридор, центральный холл, зоны); 4 геометрический поиск; 5 построение стен; 6 лестница/двери/окна; 7 обязательная мебель; 8 независимая полная валидация; 9 ранжирование допустимых кандидатов. Backtracking, локальный поиск, ограниченный набор шаблонов. Алгоритм без внешней ИИ-модели.

**Score:** соседства 30%, циркуляция 25%, эргономика 20%, ориентация/окна 15%, простота 10%. Каждый компонент 0..1; нормализовать веса при отсутствии ориентации. Детерминированный seed и stepBudget; около 10 секунд — ориентир, не гарантия. Расширенный поиск — отдельное действие.

**Статусы:** success(candidate,score,optimalityProven,stopReason?), infeasible только при формальном доказательстве в заданной конечной модели, timeout, stepLimit, cancelled, invalidInput, internalError. Если найден допустимый кандидат до исчерпания бюджета — success с optimalityProven=false. Не называть отсутствие решения в ограниченных шаблонах глобальной невозможностью.

**Компенсация:** после сдвига ненесущей стены искать изменения L1 затронутые комнаты, L2 соседи, L3 связанный блок, L4 этаж. Лексикографически минимизировать число изменённых комнат, число стен, суммарное смещение, ухудшение эргономики, изменение вспомогательных областей. Не менять целевые площади. Невозможную операцию отклонить без изменений. Пример: две комнаты 4×4 м, сдвиг стены на 200 мм даёт 16,8/15,2 м² — недопустимо без компенсации.
