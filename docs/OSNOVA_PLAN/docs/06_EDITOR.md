# v2.6 — Редактор и компенсация

> **Архив от 15.10.2026, не действующее ТЗ или инструкция.** Для v1 применяются [V1_SPECIFICATION.md](../V1_SPECIFICATION.md), для порядка работы — [IMPLEMENTATION_PLAN.md](../IMPLEMENTATION_PLAN.md). При расхождении они имеют приоритет над текстом ниже. Старые допуски, статусы поиска, объём редактора, маршруты и проверки не переносить в реализацию без сверки; приёмка v1 — раздел 11 спецификации. Исходный текст сохранён для истории.

Desktop SVG: выделение, панорамирование, zoom, сетка, размеры, точные числовые поля; ненесущие перегородки, двери/окна, мебель, функциональные зоны, ограниченная лестница. Drag snap 10 мм, числовой ввод 1 мм. Физическое объединение через удаление допустимой перегородки, виртуальное через функциональные зоны. Locked стены неизменяемы.

Атомарный цикл: `ProjectCommand(baseRevision) → immutable candidate → solveEdit → validate → preview(diff,площади,изменённые стены) → пользователь подтверждает → Controller commit → IndexedDB save → invalidation estimate`. При невозможности компенсации или отмене исходный проект сохраняется. Удаление стены меняет материальный след и площадь — пересчёт обязателен. Требования комнат после объединения сохраняются через зоны.

Undo/Redo в памяти: один подтверждённый пользовательский шаг включает все косвенные изменения комнат, дверей, зон и стен. Новый шаг очищает redo. Снимки долговременные отдельно. Ошибка IndexedDB не может сопровождаться ложным «сохранено».
