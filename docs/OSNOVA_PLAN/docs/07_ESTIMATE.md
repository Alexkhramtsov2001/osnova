# v2.7 — Геометрическая смета

> **Архив от 15.10.2026, не действующее ТЗ или инструкция.** Для v1 применяются [V1_SPECIFICATION.md](../V1_SPECIFICATION.md), для порядка работы — [IMPLEMENTATION_PLAN.md](../IMPLEMENTATION_PLAN.md). При расхождении они имеют приоритет над текстом ниже. Старые допуски, статусы поиска, объём редактора, маршруты и проверки не переносить в реализацию без сверки; приёмка v1 — раздел 11 спецификации. Исходный текст сохранён для истории.

`QuantityTakeoff` выводится из фактической геометрии: union стен и вычитание проёмов, площади/объёмы стен, перекрытия с проёмами, лестница, кровля (упрощённые односкатная/двускатная/вальмовая, уклон и свес), фундамент (лента/плита/сваи — предварительно), отделка, работы и доставка. Никакого двойного счёта L/T/X стыков, slab void и региональных коэффициентов.

Каждая позиция: stageId, materialId?, quantity, unit, unitPrice, laborPrice, total, source (`geometry|heuristic|manual`), assumptions, geometryRevision, pricingRevision, catalogVersion. Результат: ориентировочная сумма, диапазон, этапы, материалы, работы, доставка, сроки, предупреждения и допущения.

Общий со старым калькулятором — справочник цен, коэффициенты, стадии, представление результата. **Нельзя** подавать синтетический `HouseParameters` в быстрый калькулятор и называть его результат точным геометрическим расчётом. Геометрическое изменение инвалидирует количества и смету; ценовое — только стоимость; переименование — ни то ни другое. PDF только из согласованной ревизии.
