# v2.9 — Интерфейс

Маршруты `/plan`, `/plan/new`, `/plan/projects`, `/plan/project/:id` и опционально смета. Проверить React Router basename и GitHub Pages deep links.

Мастер из пяти шагов: 1 габариты/этажность/технология; 2 комнаты и строгие чистые площади; 3 этажи/лестница; 4 соседства/ориентация/вход; 5 сводка и валидация. Генерация показывает реальные стадии, отмену и причины ограничений, не выдумывает процент. Предыдущий подтверждённый план сохраняется при неудаче.

Desktop: сверху название, этаж, Undo/Redo, save/export; слева инструменты и комнаты; центр SVG; справа свойства, target/actual, ошибки; смета и снимки. Mobile: просмотр, мастер, генерация, смета, экспорт, без прецизионного редактирования. Keyboard/focus/контраст/screen-reader сообщения, доступные размеры элементов. Без регистрации и без автоматической загрузки в Supabase. Из каталога/быстрого калькулятора предварительно заполняются только действительно известные поля.
