# Согласование противоречий и открытые решения

> **Архив от 15.10.2026, не действующее ТЗ или инструкция.** Для v1 применяются [V1_SPECIFICATION.md](../V1_SPECIFICATION.md), для порядка работы — [IMPLEMENTATION_PLAN.md](../IMPLEMENTATION_PLAN.md). При расхождении они имеют приоритет над текстом ниже. Старые допуски, статусы поиска, объём редактора, маршруты и проверки не переносить в реализацию без сверки; приёмка v1 — раздел 11 спецификации. Исходный текст сохранён для истории.

1. Room polygon из v2.13-B не должен конкурировать со стеновой сетью v2.12: стены и области — канон, room polygon — вычисляемый кэш.
2. Внутренние doubled-mm координаты дают четверти мм²; допуск 5000 мм² сравнивать с 20000 areaQ4.
3. Ввод десятичной площади конвертировать точно, без скрытого округления; ограничить точность ввода и явно валидировать.
4. `infeasible` только при доказательстве, ограниченный поиск не доказывает глобальную невозможность.
5. Slab opening верхнего этажа и лестничный след нижнего — разные физические сущности.
6. Snapshot отдельно, не включать рекурсивно в Project.
7. Project revision и format version — разные вещи.
8. Durable-save failure не может сопровождаться «Сохранено».
9. Существующий быстрый калькулятор не является геометрическим движком.
10. Требуют инженерной проработки: окончания стен и наружные углы, точное сопоставление ID комнат, правила материалов на стыках, runtime schemas, лимиты файлов/объектов, конструктивные шаблоны, мобильный Safari.
