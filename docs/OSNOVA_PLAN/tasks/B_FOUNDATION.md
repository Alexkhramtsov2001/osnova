# B — основа, геометрия и независимая проверка

Карточки документации v3.0. Общие правила, команды и критерий перехода — в [IMPLEMENTATION_PLAN.md](../IMPLEMENTATION_PLAN.md). Пути относятся к отдельному osnova-plan и являются планируемыми, если их ещё нет. Статус всех карточек — planned, кроме B01 (done локально). Одна карточка/подзадача за запрос; будущие F/G/H сначала уточняются отдельным контрактом.

- **Команды:** Ничего не перезапускать: сверка исторического журнала и файлов.
- **Приёмка:** done локально; модель не реализована.
- **Ручная проверка:** Сверить файлы и локальный PROGRESS, не переписывать оболочку.
