# E — интеграция с OSNOVA только по поручению

Карточки документации v3.0. Общие правила, команды и критерий перехода — в [IMPLEMENTATION_PLAN.md](../IMPLEMENTATION_PLAN.md). Пути относятся к отдельному osnova-plan и являются планируемыми, если их ещё нет. Текущие статусы и границы выполненного — в [PROGRESS](../PROGRESS.md); будущие возможности не считаются реализованными по наличию карточки. Одна карточка/подзадача за запрос; будущие F/G/H сначала уточняются отдельным контрактом.

## E01 — Контракт упаковки core/UI

- **Цель:** Получить самостоятельный проверяемый результат: контракт упаковки core/ui.
- **Зависимости:** `S04`
- **Файлы:** Документ интеграции; будущие package boundaries.
- **Реализация:** Менять только названную область, соблюдать SPECIFICATION и профиль выпуска; не создавать модули следующих карточек.
- **Тесты:** Проверка зависимостей/React instance/base, план отката.
- **Команды:** P-core для названных unit-файлов и изменённых TS; не запускать отсутствующий generate до C11.
- **Приёмка:** Один источник кода, не копирование расходящихся исходников; сначала контракт.
- **Ручная проверка:** Проверить понятность результата и отсутствие заявлений о несуществующих возможностях.
- **Переход:** все проверки этой карточки подтверждены в локальном PROGRESS, отсутствуют неразобранные регрессии; затем только отдельно порученная карточка с выполненными зависимостями. Pending-разрешение/реальный iPhone не засчитывать выполненным.
