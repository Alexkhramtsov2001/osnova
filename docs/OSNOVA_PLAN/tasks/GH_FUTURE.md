# G/H — дополнительные виды и исследовательские границы

Карточки документации v3.0. Общие правила, команды и критерий перехода — в [IMPLEMENTATION_PLAN.md](../IMPLEMENTATION_PLAN.md). Пути относятся к отдельному osnova-plan и являются планируемыми, если их ещё нет. Текущие статусы и границы выполненного — в [PROGRESS](../PROGRESS.md); будущие возможности не считаются реализованными по наличию карточки. Одна карточка/подзадача за запрос; будущие F/G/H сначала уточняются отдельным контрактом.

## G01 — Контракт 2D → 3D

- **Цель:** Зафиксировать/проверить конкретный будущий контракт: контракт 2d → 3d.
- **Зависимости:** `F15`
- **Файлы:** Будущие модули видов/обмена; файлы определяются малым контрактом.
- **Реализация:** Сначала определить формат входа/выхода, ошибки, пределы и независимые примеры; перечисление возможностей не является поручением писать всё сразу.
- **Тесты:** Единицы/высоты/void/revision.
- **Команды:** P-contract; перед последующей реализацией уточнить действующие scripts и выделить атомарные подзадачи.
- **Приёмка:** Read-only renderer из того же документа.
- **Ручная проверка:** Перед кодом уточнить конкретный формат/образец/проверку; крупную возможность разделить.
- **Переход:** все проверки этой карточки подтверждены в локальном PROGRESS, отсутствуют неразобранные регрессии; затем только отдельно порученная карточка с выполненными зависимостями. Pending-разрешение/реальный iPhone не засчитывать выполненным.

## G03 — Лестница, крыша, террасы и балконы в 3D

Будущий read-only просмотр из того же подтверждённого канона, после G02. Семантика контуров/наружных площадок и зависимость принятия 2D — [F14](F_CAD.md#f14--непрямоугольные-дома-террасы-и-балконы). Визуализация работает локально в браузере; сервер/ИИ не являются зависимостью плана. Это геометрический концепт, не расчёт прочности/ограждений/гидроизоляции. Условные опоры/материалы нельзя выдавать за проект конструкции.

Не экстраполировать прямоугольную двускатную эвристику на Г/Т/П: неподдержанная крыша явно отсутствует/помечена, а не скрывает вырез дома                  |

Зависимости родителя G03: G02 и завершённые G03.1–G03.5. G03 завершается после этих пяти шагов, без обещания фотореализма. Каждый шаг начинает собственный малый контракт с конкретными API/единицами/файлами/образцами, затем получает P-core/P-ui проверки по реализации. Математическое совпадение/скриншот/реальный Safari — отдельные свидетельства. Тяжёлые материалы/камера относятся к G04. Более сложная кровля и строительные узлы требуют отдельных будущих контрактов, без фиктивной геометрии.
