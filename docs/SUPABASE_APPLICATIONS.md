# Демонстрационные заявки через Supabase

ОСНОВА — портфолио-проект без бюджета на сервер. Заявка подтверждает работу цепочки «калькулятор → Supabase → результат в интерфейсе». Она **не** создаёт запрос на строительство и не содержит контактов посетителя. Для реальной связи с автором остаются email, Telegram и ВКонтакте.

## Что работает

В калькуляторе кнопка «Отправить тестовую заявку» вызывает `submit_demo_request` в бесплатном проекте Supabase `ykmuwefaohpkmfdjxjkx`. Передаются только случайный UUID запроса, номер концепта из каталога (если выбран), коды типа проекта и региона, площадь, режим строительства, коды выбранных этапов, округлённый ориентир стоимости и версия демо-данных. Свободного текста, имени, телефона, email, адреса участка и файлов в записи нет. После ответа пользователь видит номер сохранённой записи; при ошибке доступна повторная попытка с тем же UUID.

Схема описана в `supabase/migrations/20261013220000_demo_requests.sql`. Она применена к текущему проекту через SQL Editor 13.10.2026; в журнале миграций CLI эта ручная операция пока не отмечена, поэтому скрипт допускает повторное применение. Таблица `demo_requests` закрыта от чтения и прямой записи браузерными ролями; функция принимает только ограниченные значения, повторную отправку с тем же UUID не дублирует и ограничивает поток до 100 записей в сутки. Проверка SQL-прав прошла на текущем проекте. Публичный ключ в коде — publishable key, пригодный для браузера; секретных ключей в репозитории нет.

Для проверки: отправить тестовую заявку из калькулятора, увидеть короткий номер и открыть `Table Editor → demo_requests` в панели Supabase. Публичный запрос на чтение таблицы должен получать отказ. SQL-проверки прав описаны в `supabase/tests/demo_requests_security.sql`.

## Границы демо

- Проект Supabase расположен в Ирландии, поэтому форма не предназначена для персональных данных посетителей. Не добавлять поля контактов или свободного текста к этой схеме.
- На бесплатном тарифе [проект может приостанавливаться при низкой активности](https://supabase.com/docs/guides/platform/free-project-pausing). В этом случае кнопка покажет ошибку до возобновления проекта в панели Supabase.
- Данные калькулятора, цены и сроки условные. Администратор может увидеть записи в Supabase Studio; отдельной панели менеджера и email-уведомлений пока нет.
- Для настоящих обращений потребуется отдельный продуктовый и правовой этап. Он не входит в текущую демонстрационную форму.
